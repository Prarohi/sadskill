# sad-backend

Execute the `backend` workflow of `sadskill` on: $ARGUMENTS

Follow `skills/sadskill/SKILL.md` and `skills/sadskill/modes/backend.md`:
1. Check `.sad/decisions.md` and `.sad/history.md`.
2. Read `~/.sadskill/profile.md` if present.
3. Apply the Human-Voice protocol.
4. Schema-first design: define explicit types, constraints, and relationships.
5. Create reversible migrations (UP and DOWN scripts).
6. Implement Row Level Security (RLS) policies and least-privilege role permissions.
7. Optimize indexes and queries; construct robust API validation contracts and tests.
