# sad-design

Execute the `design` workflow of `sadskill` on: $ARGUMENTS

Follow `skills/sadskill/SKILL.md` and `skills/sadskill/modes/design.md`:
1. Check `.sad/design-memory.md` for existing palettes, typography, and past feedback.
2. Read `~/.sadskill/profile.md` if present for local aesthetic preferences.
3. Apply the Human-Voice protocol.
4. Establish design tokens, surface mode (Persuade, Operate, Read, Experience), responsive layout, and a11y standards.
5. Enforce craft floor (touch targets >= 44px, no layout shift, reduced-motion, focus rings).
6. Perform self-critique against `ui-polish-20-tips` and update `.sad/design-memory.md`.
