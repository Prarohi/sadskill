# sad-plan

Execute the `plan` workflow of `sadskill` on: $ARGUMENTS

Follow `skills/sadskill/SKILL.md` and `skills/sadskill/modes/plan.md`:
1. Check `.sad/` project memory (`.sad/history.md`, `.sad/decisions.md`, `.sad/plans/`).
2. Read `~/.sadskill/profile.md` if present for local preferences.
3. Apply the Human-Voice protocol (direct, natural, no AI buzzwords).
4. Apply the Grilling protocol: ask about real ambiguities with recommended answers.
5. Formulate A-to-Z plan with architecture, file changes, test verification, and rollback strategy.
6. Write plan to `.sad/plans/<YYYY-MM-DD>-<slug>.md` and wait for confirmation.
