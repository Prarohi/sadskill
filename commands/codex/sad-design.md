# `/sad-design`

Execute the `design` workflow of `sadskill`.

## Instructions
1. Load and adhere to `sadskill`:
   - Inspect `.sad/` project memory, specifically `.sad/design-memory.md` (colors, typography, past feedback).
   - If `~/.sadskill/profile.md` exists, respect local design preferences.
   - Enforce the Human-Voice protocol.
2. Follow `skills/sadskill/modes/design.md`:
   - Define design tokens, surface mode (Persuade, Operate, Read, Experience), typography, and color palette.
   - Apply craft floor: touch targets >= 44px, zero layout shift, accessibility contrast, reduced motion support.
   - Run self-critique against `ui-polish-20-tips` and record choices in `.sad/design-memory.md`.
